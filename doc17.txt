HikIot开放平台Android SDK使用说明
简介
本文档用于说明HikIot开放平台SDK Android版本接口之间的关系以及接口调用顺序，对开放平台SDK Android版本各接口都有详细的说明。
如集成本SDK及插件服务，建议您提前告知您的用户涉及以下隐私协议政策：
海康互联开放平台应用开发SDK隐私政策
名词解释
名词	注解
appKey	登录接口返回
httpUrlToken	非设备操作的token，通过getHttpToken获取，初始化sdk时传入
streamLiveToken	预览需设置的token
streamRecToken	回放需设置的token
streamTalkToken	对讲时需设置的token
deviceToken	设备类请求token
deviceGlobalToken	通道类请求token，通道相关底层请求需用到
deviceVideoToken	通道类请求token，通道相关底层请求需用到
DeviceSerial	设备序列号
CameraNo、ChannelNo	设备通道号
OSD	视频播放当前时间
PTZ	云台控制，可以通过终端控制操作设备
功能介绍

账号对接(授权登录、sdk接口登录)	授权到HikIot平台，复用HikIot平台能力
摄像头列表	得到对应账号下设备
直播	登录接口直播，可设置直播分辨率
查看回放（SD卡、录像机、云存储）	回放

获取到 appAccessToken 后，Demo 需要使用到该 token 和对应的账号、密码进行授权登录，登录成功后，即可获取到账号下的设备列表，而且，后续接口调用也需要登录接口返回的 userAccessToken 进行鉴权。

SDK初始化

1、使用平台申请的App AccessToken和账号密码登录
2、获取到httpToken和appKey
3、通过sdk 初始化

    HikIotOpenSDK.instance.login(appAccessToken,account,pwd,
        object : LoginCallback {
            override fun onLoginSuccess(result: LoginResult?) {
                //1、登录成功后获取httpToken和appKey
                getHttpTokenAndInit()
            }

            override fun onLoginFailed(code: Int, msg: String, throwable: Throwable?) {
                Toast.makeText(this@MainActivity,msg,Toast.LENGTH_LONG).show()
            }

        })

//2、获取httpToken和appKey
    private fun getHttpTokenAndInit(){
        HikIotOpenSDK.instance.getHttpToken(object: BaseCallback<HttpTokenBean>{
            override fun onSuccess(result: HttpTokenBean?) {
                val tokenAppKey = result?.tokenAppKey?:return//参数异常
                val httpUrlToken = result?.httpUrlToken?:return//参数异常
                HikIotOpenSDK.instance.init(HikIotDemoApp.getApp(),tokenAppKey,httpUrlToken)//3、使用HikIotOpenSDK初始化
                Log.d("token打印","${result}")
            }

            override fun onFailed(code: Int, msg: String, throwable: Throwable?) {
                Toast.makeText(HikIotDemoApp.getApp(),msg,Toast.LENGTH_LONG).show()
            }

        })
    }

直播

步骤

1.创建播放器,绑定SurfaceHolder
2.设置handler回调、设备如果设置了视频加密，需要设置视频加密密码，默认为设备的6位验证码
3.启动播放
4.停止播放
5.释放播放器

实例代码如下

    HikIotPlayer player  = HikIotOpenSDK.instance.createPlayer(String deviceSerial,int cameraNo);

    //设置Handler, 该handler将被用于从播放器向handler传递消息
    player.setHandler(mHandler);

    //设置播放器的显示Surface
    player.setSurfaceHold(mHolder);

    /**
     * 设备加密的需要传入密码
     * 传入视频加密密码，用于加密视频的解码，该接口可以在收到ERROR_INNER_VERIFYCODE_NEED或ERROR_INNER_VERIFYCODE_ERROR错误回调时调用
     * @param verifyCode 视频加密密码，默认为设备的6位验证码
     */
    player.setPlayVerifyCode(String verifyCode);

    //开启直播
    player.startRealPlay();

    //停止直播
    player.stopRealPlay();

    //释放资源
    player.release();

回放

步骤

1.创建播放器,绑定SurfaceHolder
2.设置handler回调、设备如果设置了视频加密，需要设置视频加密密码，默认为设备的6位验证码
3.启动播放
4.停止播放
5.释放播放器

实例代码如下

    HikIotPlayer player  = HikIotOpenSDK.instance.createPlayer(String deviceSerial,int cameraNo);

    //设置Handler, 该handler将被用于从播放器向handler传递消息
    player.setHandler(mHandler);

    //设置播放器的显示Surface
    player.setSurfaceHold(mHolder);

    /**
     * 设备加密的需要传入密码
     * 传入视频加密密码，用于加密视频的解码，该接口可以在收到ERROR_INNER_VERIFYCODE_NEED或ERROR_INNER_VERIFYCODE_ERROR错误回调时调用
     * @param verifyCode 视频加密密码，默认为设备的6位验证码
     */
    player.setPlayVerifyCode(String verifyCode);
    /**
     * 开始云存储远程回放
     * @param cloudFile 云存储文件信息  参见下文中的 查询云存储录像信息列表
     * @return  true 表示成功， false 表示失败
     */
    player.startPlayback(EZCloudRecordFile cloudFile)
    
    //或者
    /**
     * 开始远程SD卡回放
     * @param deviceFile SD卡文件信息  参见下文中的 查询远程SD卡存储录像信息列表
     * @return  true 表示成功， false 表示失败
     */
    player.startPlayback(EZDeviceRecordFile deviceFile)
    
    //或者
    /**
      * 开始远程SD卡回放---按时间回放
      * @param startTime 开始时间
      * @param stopTime 结束时间
      * @return  true 表示成功， false 表示失败
      */
    player.startPlayback(Calendar startTime, Calendar stopTime)


    /**
      *  停止远程回放
      */
    player.stopPlayback()

    //释放资源
    player.release();

////////////下载本地回放，即sd卡、硬盘上的回放
 val strRecordFilePath: String = DIR + System.currentTimeMillis() + ".mp4"
 val file = File(strRecordFilePath)
 if (!file.parentFile.exists()) {
     file.parentFile.mkdirs()
 }
 localDownloader = EZDeviceStreamDownload(strRecordFilePath, deviceSerial, channelNo, EZDeviceRecordFile().apply {
     startTime = recordFile?.startTime
     stopTime = recordFile?.stopTime
 })//声明下载器，指定strRecordFilePath（下载路径）、deviceSerial（设备序列号）、channelNo（通道号）、EZDeviceRecordFile（回放时间范围）

对讲说明

对讲流程需要根据设备的对讲能力进行区分处理。EZDeviceInfo中的isSupportTalk可获取到设备的对讲能力，0-不支持对讲，1-支持全双工对讲，3-支持半双工对讲。 同一设备需要开启不同功能（直播/回放/对讲）的播放器时，需要分别对每个功能创建一个播放器。播放器的功能是单一的

关于对讲功能，如果播放有声音输出，则在开启对讲前需要关闭播放的声音closeSound，关闭对讲后开启播放的声音openSound，详见demo；

开始对讲之后在消息回调中会收到

a、成功消息：113 （RealPlayMsg.MSG_REALPLAY_VOICETALK_SUCCESS），
b、失败消息：114 （RealPlayMsg.MSG_REALPLAY_VOICETALK_FAIL），失败回调时查看errorCode，如果为400035（需要输入验证码）和400036（验证码错误），则需要开发者自己处理让用户重新输入验证密码，并调用setPlayVerifyCode设置密码，然后重新启动播放。

Demo 中用到的接口梳理

Demo 中会用到开放平台提供的一些接口，接口说明请参考 开放平台上的开发文档，如下：

授权登录：/v1/open/sdk/login，授权登录接口中返回的 userAccessToken 以及授权登录页的 appAccessToken，在登录成功后，需要设置到 http 请求的 header 中，具体参考 Demo
获取设备列表：/device/v1/page
获取非设备操作 token：/device/v1/token/device/get
获取设备 token：/device/v1/token/ops/get
获取设备/通道能力集：/device/v1/getDeviceCapacities
获取清晰度：/device/direct/v1/streamingMedia/getAttrs

注意：

授权登录接口的域名与其它接口的域名不一样，授权登录接口的域名是 api.hikiot.com，而其它接口的域名是 open-api.hikiot.com
Demo 整体代码是比较复杂的，主要是涉及到一些复杂的 UI 及状态变化，尤其是回放模块。但是，若只是开发预览、回放、对讲、云台、截图、录制等功能，实现是比较简单的，具体可以参考本文上面的章节。对于 UI 及交互方面，您可以按照自己的需求进行设计开发，Demo 仅供参考。
